# 🎓 StudyHub — مركز الدراسة

موقع شخصي واحد يجمّعلك كل حاجة: **مهامك** + **تقدمك في مواقعك التلاتة** في صفحة واحدة.

```
studyhub/
├── index.html      ← التطبيق كله (لا admin ولا user — ده ليك إنت بس)
├── css/style.css   ← ستايلات مخصوصة فوق Tailwind
├── js/app.js       ← كل المنطق (مهام + مصادر + ثيم + نسخ احتياطي)
└── README.md       ← الملف ده
```

**رفعه على Vercel:** اسحب فولدر `studyhub` في vercel.com/drop زي باقي المواقع بالظبط — اللينك نفسه هو التطبيق (مفيش `/user/`).

## 🎯 الفكرة

| السؤال | الإجابة |
|---|---|
| الموقع بيعمل إيه؟ | تتبّع مهام + عرض تقدمك من 3 مواقع في مكان واحد |
| الربط إزاي؟ | **ملفات تقدم** — كل موقع فيه زرار «⬇️ حمّل تقدمي»، وترفع الملف هنا (اختيارك: لينكات المواقع تفضل منفصلة زي ما هي) |
| أنهي أقسام؟ | المواد: **اتصالات وحاسبات** · الكورسات: **الاتصالات والحاسبات** · السايبر: **الموقع كله** |
| مهامي الشخصية؟ | **كاملة**: عنوان + ملاحظات + تصنيف + أولوية + تاريخ تسليم + سحب وإفلات |
| الثيم؟ | **تلقائي حسب جهازك** + زرار تثبيت يدوي |
| الاسم؟ | **StudyHub — مركز الدراسة** |

## 🧩 اللي اتبنى

### ✅ مهامي (كاملة)
- مودال إضافة/تعديل واحد: عنوان (إجباري)، ملاحظات، تصنيف (مذاكرة/مشروع/كورس/شخصي)، أولوية (عالية/متوسطة/منخفضة)، تاريخ تسليم.
- فلاتر بعدادات: الكل · متأخرة · النهارده · قيد التنفيذ · مكتملة.
- شارات ذكية للتاريخ: «النهارده / بكره / بعد ٣ يوم / متأخر من يومين» (المتأخر بالأحمر).
- ترتيب **سحب وإفلات** من اليد ⠿ في فلتر «الكل» — شغال موبايل وديسكتوب (Pointer Events مش HTML5 DnD).
- زرار ✓ بيعلّم الإتمام ويسجّل وقته («خلّصتها إمبارح»)، وسطر المكتمل بيتخطّط.

### 🛰️ المصادر المربوطة (3 كروت)
كل كارت: حلقة نسبة، X/Y مكتمل، «آخر مزامنة من …»، مجموعات قابلة للطي بأسماء العناصر وحالتها ✓، زرار **تحديث من ملف**، زرار **افتح الموقع** (بتحط لينك كل موقع مرة واحدة ⚙️ بيتحفظ عندك)، وزرار مسح بيانات المصدر من هنا بس.

**ملفات التصدير اللي بيفهمها** (صيغة `studyhub-progress`):
```json
{ "app": "eng-materials|eng-roadmap|cyberpentest-roadmap", "type": "studyhub-progress",
  "label": "اسم ودّود", "stats": { "total": 12, "done": 5 },
  "groups": [ { "id": "...", "name": "Level 100", "items": [ { "id": "c1", "name": "برمجة", "done": true } ] } ] }
```
- بيرفض ملف موقع غلط برسالة واضحة («ده ملف موقع تاني — استورده في الكارت الصح»).
- **توافقية**: ملف السايبر القديم (`{progress: {id: true}}`) بيتقبل — بيعرض العدد المكتمل وبيحذّر إن الأسماء محتاجة ملف أحدث. الماب الخام لازم كل قيمها `true` بالظبط (حماية من ملفات غريبة).

### 🌗 الثيم التلقائي
- أول زيارة: يتبع تفضيل جهازك (داكن/فاتح)، ولو غيّرته والموقع مفتوح يتحوّل لحظيًا.
- أول ما تدوس زرار 🌙/☀️ اختيارك بيتثبّت ويتفضّل (`studyhub_theme_v1`).

### 💾 نسخة احتياطية كاملة
زرار في الهيدر ينزّل `studyhub-backup.json` (مهام + مصادر + لينكات) — وزرار استرجاع بيرجّع كل حاجة على أي جهاز. ملفات غير صالحة مرفوضة برسالة.

### 🔐 احتياطات مبنية من أول يوم
- Tailwind **مثبّتة بإصدار** (`@4.3.3`) مش «آخر نسخة»، وFont Awesome 6.7.2 **ببصمة SRI** — المتصفح هيرفض المكتبة لو اتعبث بيها على الـ CDN.

## 🚀 طريقة الاستعمال (دقيقة واحدة)
1. ارفع `studyhub` على Vercel.
2. من كل موقع من مواقعك: دوس «⬇️ حمّل تقدمي» (سايبر = Download My Progress الموجود).
3. افتح StudyHub → كارت كل مصدر → **استيراد ملف التقدم** → ارفع الملف.
4. حط لينك كل موقع من زرار «حط اللينك» مرة واحدة — وبعدها «افتح الموقع» بضغطة واحدة.
5. كل فترة: حدّث الملفات → «تحديث من ملف». خلاص 🎉
